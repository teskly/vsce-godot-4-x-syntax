# Changelog

## 0.1.1

- Added a client for the built-in Godot 4.x GDScript Language Server.
- Added configurable LSP host and port settings with defaults `127.0.0.1:6005`.
- Added connection status, reconnect commands and diagnostics for LSP connection failures.

## 0.1.0

- Added syntax highlighting for GDScript 4.x.
- Added syntax highlighting for `.tscn`, `.tres`, `project.godot`, `.gdshader`, `.gdshaderinc` and `.gdextension`.
- Added GDScript snippets and format-specific language configurations.
